# Rest and Render

An art-driven sticker and greeting card shop with themed collections and interactive vending-machine experiences. The project is in planning; there is no storefront or application setup yet.

## Local folders

- `1997 Vending dreams/` — artwork and references for the 1990s vending experience.
- `ART/` — original product artwork and production files.
- `Assets/` — general website artwork and branding.
- `LOCAL-SECRETS/` — local credentials; never commit this folder.

These folders are kept local and ignored by Git until artwork publication is explicitly approved. Product images uploaded to a future shop are separate from local originals.

## Project documents

- `PHASES.md` — roadmap, phase gates, review checklists, and signoffs.
- `WISHLIST.md` — ideas retained in an append-only history.
- `TECH-STACK.md` — approved and undecided technology and account references.
- `CHANGELOG.md` — production releases actually shipped.
- `AGENTS.md` — working instructions for coding agents.

The GitHub repository is public. Review the precise files and artwork before any staging or push.
